Autodesk Fusion connection

This local add-in uses the Fusion account already signed in on your PC. No Autodesk password or cloud API key is needed.

  1. Install the Fusion add-in below.
  2. In Fusion: Utilities → Scripts and Add-Ins → Add-Ins → AeroDeskLink → Run. Enable Run on Startup.
  3. Open your design and click Send to AeroDesk in Fusion’s Utilities panel.
  4. Import the latest design below. Re-export after CAD changes, then import again to refresh.
